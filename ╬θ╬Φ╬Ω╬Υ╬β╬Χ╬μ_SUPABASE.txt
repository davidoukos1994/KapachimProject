KapaChim Project v2 — Οδηγίες

1. Το ενιαίο SUPABASE_SETUP.sql έχει ήδη εκτελεστεί, επομένως για τη v2 δεν χρειάζεται νέο SQL.
2. Ανέβασε ΟΛΑ τα αρχεία αυτού του ZIP στο GitHub repository, αντικαθιστώντας την προηγούμενη έκδοση.
3. Περίμενε να ολοκληρωθεί το GitHub Pages deployment και άνοιξε ξανά την εφαρμογή.
4. Η εφαρμογή:
   - φορτώνει τους κοινόχρηστους τομείς και τα έγγραφα από το Supabase,
   - αποθηκεύει online κάθε αλλαγή κειμένου/τομέα/εγγράφου,
   - ανεβάζει φωτογραφίες στο bucket manual-media,
   - συγχρονίζει τις αλλαγές σε όλες τις συσκευές μέσω Realtime.
5. TXT, DOCX και copy-paste από Σημειώσεις iPhone υποστηρίζονται στις φόρμες κειμένου, τομέων και εγγράφων.

Σημείωση: Η έκδοση είναι χωρίς PIN/login, όπως ζητήθηκε. Όποιος ανοίγει την εφαρμογή μπορεί να επεξεργάζεται το κοινόχρηστο περιεχόμενο.
