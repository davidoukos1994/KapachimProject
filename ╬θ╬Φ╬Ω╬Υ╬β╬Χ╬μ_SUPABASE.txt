KAPACHIM CUSTOM MANUAL V19 — SUPABASE

1. Ανέβασε ολόκληρο το περιεχόμενο του ZIP στο GitHub repository.
2. Το Supabase setup έχει ήδη εκτελεστεί από προηγούμενη έκδοση, οπότε δεν χρειάζεται νέο SQL για τη V19.
3. Η εφαρμογή ανοίγει απευθείας με διαθέσιμη επεξεργασία — δεν υπάρχει PIN ή λειτουργία διαχειριστή.
4. Κάθε αποθήκευση κειμένου, τομέα, εγγράφου, σημείωσης ή φωτογραφίας στέλνεται στο Supabase.
5. Όλες οι συσκευές που ανοίγουν την ίδια εφαρμογή βλέπουν τα ίδια συγχρονισμένα δεδομένα.
6. Οι φωτογραφίες DCS, εξωτερικού χώρου και οι φωτογραφίες ανά βήμα αποθηκεύονται στο Supabase Storage.
7. Το GitHub χρειάζεται μόνο όταν αλλάζει ο κώδικας ή η εμφάνιση της εφαρμογής.
8. Για αλλαγές περιεχομένου μέσα από την εφαρμογή δεν χρειάζεται νέο ZIP ή νέο ανέβασμα στο GitHub.

ΣΗΜΑΝΤΙΚΟ
Η V19 είναι σκόπιμα απλή: όλοι όσοι ανοίγουν την εφαρμογή μπορούν να δουν τα κουμπιά επεξεργασίας. Οι αλλαγές αποθηκεύονται online και συγχρονίζονται σε όλους.
