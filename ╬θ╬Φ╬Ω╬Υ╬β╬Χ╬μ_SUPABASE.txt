KAPACHIM CUSTOM MANUAL V15 — ΟΔΗΓΙΕΣ

1. Μπες στο Supabase project.
2. Άνοιξε SQL Editor > New query.
3. Αντέγραψε όλο το SUPABASE_SETUP.sql και πάτησε Run μία φορά.
4. Ανέβασε ΟΛΑ τα αρχεία αυτού του ZIP στο GitHub Pages.
5. Άνοιξε την εφαρμογή και πάτησε «Διαχειριστής».
6. Βάλε PIN 7669. Την πρώτη φορά δημιουργείται αυτόματα η online βάση του manual.

ΤΙ ΣΥΓΧΡΟΝΙΖΕΤΑΙ ONLINE
- Αλλαγές σε τομείς, σκοπό, ιδιότητες, περιγραφές και σειρά.
- Αλλαγές στα έγγραφα, εκκινήσεις, σταματήματα και αναλύσεις.
- Νέοι τομείς.
- Πρόσθετες σημειώσεις.
- Φωτογραφίες DCS, εξωτερικού χώρου και φωτογραφίες ανά βήμα.

Οι άλλοι χρήστες ανοίγουν την εφαρμογή χωρίς PIN και βλέπουν τα online δεδομένα.
Το PIN αποθηκεύεται μόνο στη συσκευή/browser όπου το έβαλες.
Για αλλαγές στον κώδικα ανεβάζεις νέο ZIP στο GitHub. Για αλλαγές περιεχομένου δεν χρειάζεται GitHub.

ΣΗΜΑΝΤΙΚΟ ΓΙΑ ΑΣΦΑΛΕΙΑ
Η έκδοση αυτή χρησιμοποιεί απλό PIN στο browser, όπως ζήτησες. Το PIN προστατεύει το περιβάλλον επεξεργασίας, αλλά δεν είναι ισχυρή server-side ταυτοποίηση. Για αυστηρή ασφάλεια χρειάζεται Supabase Auth με προσωπικό λογαριασμό.
