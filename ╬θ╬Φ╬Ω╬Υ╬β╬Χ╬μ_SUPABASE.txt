KAPACHIM PROJECT v1 — ΟΔΗΓΙΕΣ ΕΓΚΑΤΑΣΤΑΣΗΣ

ΠΡΩΤΗ ΦΟΡΑ ΜΟΝΟ:
1. Άνοιξε Supabase → SQL Editor.
2. Πάτησε «New query».
3. Άνοιξε το αρχείο SUPABASE_SETUP.sql από αυτό το ZIP.
4. Αντέγραψε ΟΛΟ το περιεχόμενο στο νέο query.
5. Πάτησε Run.
6. Περίμενε να εμφανιστεί μήνυμα επιτυχίας.

ΜΕΤΑ:
1. Ανέβασε όλα τα αρχεία του ZIP στο GitHub repository, αντικαθιστώντας τα παλιά.
2. Κάνε Commit.
3. Περίμενε 1–2 λεπτά για το GitHub Pages.
4. Κλείσε και άνοιξε ξανά την εφαρμογή στο iPhone ώστε να ανανεωθεί η cache.

ΤΙ ΣΥΓΧΡΟΝΙΖΕΤΑΙ:
• Τομείς, σκοποί, ιδιότητες, περιγραφές και σειρά εμφάνισης.
• Έγγραφα, αναλύσεις, εκκινήσεις και σταματήματα.
• Πρόσθετα κείμενα και σημειώσεις.
• Εικόνες DCS και εξωτερικού χώρου.
• Φωτογραφίες δίπλα σε κάθε βήμα εγγράφου.

ΣΗΜΑΝΤΙΚΟ:
• Δεν υπάρχει PIN ή login.
• Όλες οι αλλαγές που αποθηκεύονται μέσα στην εφαρμογή πηγαίνουν στο Supabase.
• Όλες οι συσκευές βλέπουν τα ίδια δεδομένα.
• Για μελλοντικές αλλαγές στον κώδικα θα ανεβάζεις μόνο το νέο πλήρες ZIP στο GitHub,
  εκτός αν σου πω ρητά ότι απαιτείται νέα αλλαγή στη βάση.
